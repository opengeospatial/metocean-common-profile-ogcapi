[[req_collections_license]]
[requirement]
====
[%metadata]
identifier:: /req/collections/license
part:: The `links` property in a `collection` SHALL contain a link to a license of its data.
part:: The license link SHALL set the `rel` property to `license`.
part:: The `type` property SHALL be set to `text/html`.
part:: If the data is open data, the license SHALL be `CC BY 4.0` and the `href` property set to `https://creativecommons.org/licenses/by/4.0/`.
====
