[[rec_collections_vertical-extent]]
[recommendation]
====
[%metadata]
identifier:: /rec/collections/vertical-extent
part:: If ``extent.vertical`` is defined, the value of ``extent.vertical.vrs``` SHOULD be one the following values: ``Pressure level in hPa``, ``Geopotential height in gpm``, ``Geometrical altitude above mean sea level in meters``, ``Height above ground in meters``, ``Flight level``.
====
