== Scope

The MetOcean Common Profile for OGC API provides a set of Requirements, Recommendations and Permissions for the discovery, access, visualization, processing and exploitation of meteorological and oceanographic data using OGC APIs in support of deeper domain interoperability.

This document specifically supports the following:

- Discovery of MetOcean resources from OGC API
- Description of MetOcean dimensions and parameters using spatial, temporal, additional dimensions and subsets (numerical weather prediction data, weather observations, etc.)
- Description of subset nomenclature and usage (model runs, elevations, pressure levels)

This specification defines the conformance requirements for the  MetOcean Common Profile for OGC API. Annex A defines the abstract test suite. Annex B provides normative information on schemas. Annex C provides informative examples.
